# 🤖 DevTown Chatbot

An AI-powered chatbot built using Python, LangChain, and MongoDB.
This chatbot can handle conversations, store user data, and respond intelligently using LLM APIs.

## ⚙️ Installation

### 1. Clone the repository

```
git clone https://github.com/your-username/devtown_chatbot.git
cd devtown_chatbot
```

### 2. Create virtual environment

```
python -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```
pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file and add:

```
GROQ_API_KEY=your_api_key
MONGO_URI=your_mongodb_connection_string
```

---

## ▶️ Run the Project

```
python app.py
```
